# Linux Server Administration and Monitoring on AWS EC2

## Project Overview
Built and configured a Linux web server using AWS EC2
and Amazon Linux 2023.

## Technologies Used
- AWS EC2
- Amazon Linux 2023
- Linux
- Apache HTTP Server
- Bash Scripting
- Cron
- Git and GitHub

## Project Tasks
1. Created Linux users and groups.
2. Managed file permissions and ownership.
3. Installed and configured Apache.
4. Hosted an HTML website.
5. Monitored CPU, memory and disk usage.
6. Created automated monitoring scripts.
7. Scheduled monitoring using Cron.
8. Created compressed website backups.
9. Restored website files from backups.
10. Troubleshot and recovered Apache service.

## Result
Successfully hosted a website on AWS EC2
and implemented Linux monitoring and backup tasks.
